H.2 False Positives and False Negatives We distinguish the predicate-selected set from the fixed-budget set supplied to the downstream agent. Let Cq be the retrieved candidate set, Pq the predicate-selected set, and Gq the annotated required set. In this error analysis we use the authors’ nonstandard error labels: a false positive (FP) is a required skill whose evaluated predicate is false, and a false negative (FN) is a nonrequired skill whose evaluated predicate is true. Thus predicate FP counts |(Gq ∩Cq)\Pq| and predicate FN counts |Pq \ Gq|. We retain standard relevance-based TP as |Pq ∩Gq| and TN as |Cq \ (Pq ∪Gq)|; this hybrid naming is not a standard confusion-matrix convention. For set-level accounting over Cq ∪Gq, FP counts all missing required skills, |Gq \ Pq|, including retrieval misses |Gq \ Cq| listed separately below. A retrieval miss has no evaluated predicate and is not a predicate rejection. Unretrieved non-gold catalog skills do not inflate TN. For a supplied topfive set, the same set-level error labels describe missing required and extra nonrequired skills, not necessarily the underlying predicate decisions.
