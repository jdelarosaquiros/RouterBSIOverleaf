A.1
Initialization and Online Routing
793
We initialize one predicate psi for every skill s ∈S
794
from its public name, description, and body. The
795
generator receives no task labels. It produces one
796
reusable applicability statement of at most l charac-
797
ters. This limit also applies to subsequent replace-
798
ments. Compound statements may contain AND,
799
OR, and NOT, but they are evaluated as one pred-
800
icate. The improvement procedure neither adds
801
predicates nor decomposes them into separately
802
evaluated clauses.
803
For a task q, we retrieve S@k and evaluate
804
each retrieved predicate against the public task text.
805
Strict routing returns
806
Pq = {s ∈S@k : ps(q) = True}.
807
The evaluator receives only the task and predicate,
808
not Gq, a reference answer, or the skill body. Dur-
809
ing training, required-skill annotations identify the
810
failure set
811
Fq = ((Gq ∩S@k) \ Pq) ∪(Pq \ Gq).
812
A required skill outside S@k is a retrieval miss and
813
does not trigger a predicate repair.
814
We traverse the training tasks in their fixed split
815
order for each iteration. For one task, repairs to
816
distinct failed skills can execute in parallel; all re-
817
sults are joined before committing them in skill-
818
identifier order. The next task is routed with the
819
resulting predicates. This preserves sequential on-
820
line updates across tasks while allowing parallel
821
evaluator calls.
822
For a ranked rather than strictly filtered output,
823
the implementation orders candidates lexicograph-
824
ically by predicate label, retrieval score, and orig-
825
inal retrieval order, placing true labels first. This
826
is the operational interpretation of the label-based
827
prioritization in the main text; it is not an unnormal-
828
ized arithmetic sum for arbitrary retrieval scores.
829
For SkillSight, the exposed score is 1/j at retrieval
830
rank j ≥1, so adding a binary label yields the
831
same selected-first ordering. A fixed-size top-k
832
output may therefore include false-labelled candi-
833
dates, unlike strict routing.

A.2
Bounded Replay Construction
835
For each skill, we retain two training-history buck-
836
ets, H+
s and H−
s , containing at most N relevant
837
and N irrelevant tasks. Membership is determined
838
by s ∈Gq. Before routing, each newly seen train-
839
ing task is registered once in a global seen-task
840
history. After routing, we materialize the bounded
841
buckets for every retrieved or required catalog skill
842
in sorted skill-identifier order, including skills with-
843
out a routing error. A newly materialized bucket
844
replays the already-seen history; an existing bucket
845
processes the new history entries. Only these per-
846
skill buckets are capacity-limited, not the global
847
history used for lazy materialization.
848
A bucket is filled until it reaches N entries.
849
Thereafter, every newly seen task of that category
850
replaces a uniformly selected existing slot. This is
851
uniform slot replacement, not reservoir sampling:
852
the new task is always inserted. A seeded random-
853
number generator shared across buckets and the
854
deterministic materialization order determine the
855
replacements. Repeated visits to a task in later
856
iterations do not insert it again.
857
When repairing the failure on q, the effective
858
replay set is
859
Rs = H+
s ∪H−
s ∪{q},
860
with duplicate task identifiers removed. Thus the
861
historical bounds are |H+
s |, |H−
s | ≤N, while the
862
current-inclusive set can have 2N + 1 tasks if q is
863
no longer cached. The bounds in the main replay
864
description apply to the retained history; the current
865
failed task is always included in the implemented
866
decision.
867
The proposal prompt receives the current task
868
and its relevance label, plus up to the first three
869
entries from each bucket, with their existing predi-
870
cate judgments. Candidate scoring uses the entire
871
effective replay set, not just these prompt examples.
872
Bucket order, rather than a new random sample,
873
determines the displayed examples.
