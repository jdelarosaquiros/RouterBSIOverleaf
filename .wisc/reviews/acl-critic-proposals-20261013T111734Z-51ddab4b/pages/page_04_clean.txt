We conduct experiments on SRA-Bench, which comprises six capability-intensive benchmarks: TheoremQA (Chen et al., 2023), LogicBench (Parmar et al., 2024), ToolQA (Zhuang et al., 2023), CHAMP (Mao et al., 2024), MedCalcBench (Khandekar et al., 2024), and BigCodeBench (Zhuo et al., 2025). These datasets cover diverse task settings, including mathematical reasoning, formal logic, tool use, and code generation. Each instance is paired with annotated gold skill(s) and evaluated against a shared external skill corpus, enabling decomposed analysis of retrieval, incorporation, and end-task execution. We split each dataset into train, validation, and test splits with ratios of 70%, 15%, 15%, respectively. To evaluate the learning capabilities of baselines, we further filter and balance splits such that each split has at least one task that share the same required skill. 4
