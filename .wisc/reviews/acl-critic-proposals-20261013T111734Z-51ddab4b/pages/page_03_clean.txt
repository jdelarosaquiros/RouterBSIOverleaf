Selected candidate is discarded by the held-out validation gate if its validation error is higher than the initial predicate psi. 2.3 Static Routing Without Feedback-driven Optimization Static routing uses retrieval or inference-time selection without persistently optimizing routing criteria from task feedback. Similarity methods retrieve skills through semantic or lexical matching (Wang et al., 2024; Xiao et al., 2026; Su et al., 2026), while structured methods organize search through predefined hierarchies or relationships (Li et al., 2026a; Sun et al., 2026; Wang et al., 2026a; Packer et al., 2023; Liang et al., 2026; Liu et al., 2025). LLM-based methods select or compose capabilities at inference time (Chen et al., 2026b; Xia et al., 2026b; Shen et al., 2023; Zhou et al., 2024). These approaches support skill routing but do not convert failures into persistent corrections. RouterBSI uses routing failures to refine applicability predicates online in a black-box setting. 3 Problem Definition We study recursive self-improvement for skill routing, where an agent updates skill applicability predicates from routing failures while avoiding regressions. Each skill s from skill library S has a predicate ps(q) = {True or False} indicating whether it should be selected for task q. A routing failure occurs when this prediction disagrees with whether s from predicted skills Pq is in ground-truth set of required skills Gq, producing either a missing required skill or a selected irrelevant skill. Since S is a large library of skills, we only evaluate the predicates from skills in the top k based on retrieval score r(q, Ks) between task q and the skill key Ks. Given a failure in top k skills sk, the objective is to iteratively update the affected predicate psk(q) to correct the observed error without degrading previously learned or unseen routing decisions. 4 Method 4.1 Predicate-Based Skill Routing Skills are selected according to whether the task aligns with the type of task each skill is intended to handle. This is determined by evaluating the skill’s predicate statement for the given task. The predicate evaluates to true when the task aligns with the intended task type and to false otherwise. The router first retrieves the top-k skills based on the retrieval score r(q, Ks) between task q and the skill key Ks.
