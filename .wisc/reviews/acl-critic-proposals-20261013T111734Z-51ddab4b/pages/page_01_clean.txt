Recursive Self-Improvement of Predicates for Skill Routing via Minimum Bayes Risk Replay and Held-out Gates Anonymous ACL submission Abstract As agents are expected to solve broader and more complex tasks, they rely on external knowledge saved as skills to handle tasks beyond the LLM’s parametric capabilities. As the skill corpora grows into hundreds or thousands of skills, skill routing becomes a bottleneck, where the agent must efficiently retrieve and select the appropriate skills to complete a task. Recent skill routing approaches leverage task feedback to improve skill routing performance online. However, feedback-driven updates to routing criteria can regress performance, and accumulating task feedback at scale requires efficient experience management. We introduce a recursive self-improving algorithm for skill routing in a black-box setting called RouterBSI. It refines task applicability predicates using Minimum Bayes Risk (MBR) with bounded replay to minimize errors on seen tasks and a held-out validation gate to reduce regressions on unseen tasks. The router evaluates predicates for top-k retrieved skills then selects skills if the task satisfies their respective predicate. RouterBSI improves its cold-start top-5 recall of required skills by 24.9% across different retrievers on tasks from TheoremQA, LogicBench, ToolQA, MedCalc-Bench, CHAMP, and BigCodeBench sharing a 26k skill corpus. On average, it retains 90.5% of the required skills in top 5 from the top 50 skills retrieved. 1 Introduction Large language model (LLM) agents increasingly rely on reusable skills to extend their capabilities beyond knowledge encoded in model parameters. These skills package procedural knowledge that can be reused across recurring classes of tasks. As skill libraries grow, however, explicitly exposing every available skill in the context becomes increasingly impractical. Recent work therefore shifts toward Skill Retrieval Augmentation (SRA), where skills must be retrieved and loaded from a largescale skill corpora (Su et al., 2026) (Figure 1). The skill is not accepted for task q2 because it asks for the price between a range of years. In SRA, retrieval based on semantic relevance alone is not enough. Skills must be invoked based on their downstream utility for completing a task to reliably augment the agent’s capabilities. Current agents can struggle to distinguish useful skills from irrelevant ones even when the correct skill has been successfully retrieved (Su et al., 2026). We refer to skill routing as the process of determining which retrieved candidate skills are applicable to a task and should therefore enter the agent's active context for completing a task. Reliable routing must distinguish applicability from semantic relatedness: a skill can be topically similar to a task without satisfying the requirements under which its procedure should be invoked. This distinction becomes increasingly important as broader candidate sets introduce irrelevant procedures that can distract the model or interfere with downstream reasoning. Existing routing approaches address this problem through similarity scores, learned utility functions, direct model-based selection, and explicit activation conditions. Learned retrievers and rerankers can improve discrimination among candidates but encode routing criteria implicitly in model parameters and require additional optimization data and compute. In contrast, non-parametric approaches keep the underlying model fixed while modifying external state that influences future decisions.
