C.1
Task Filtering and Split Construction
1345
We use the six task collections distributed with
1346
SRA-Bench (Su et al., 2026). Table 3 gives the ex-
1347
act task and gold-skill counts after filtering. Start-
1348
ing from 5,400 annotated instances, we remove any
1349
task whose required set contains a skill occurring
1350
in fewer than three remaining tasks. We recompute
1351
skill frequencies and repeat this operation until no
1352
such task remains. Filtering removes whole tasks
1353
rather than individual labels from a multi-skill task.
1354
This leaves 4,987 tasks associated with 306 distinct
1355
gold skills; 413 tasks are excluded.
1356
We target a global train/validation/test allocation
1357
of 70%/15%/15%, yielding 3,491/748/748 tasks. A
1358
constrained allocation assigns tasks while ensuring
1359
that every retained skill occurs in all three partitions.
1360
For each skill, split counts lie within floor/ceiling
1361
bounds around the target proportions, clipped to
1362
leave at least one occurrence in each partition. The
1363
allocation minimizes normalized deviations from
1364
the target proportions for both skills and datasets,
1365
and uses split seed 20260908 to order task identi-
1366
fiers within each dataset–gold-set group. The con-
1367
straints can shift an individual dataset away from
1368
the global proportions, particularly when many
1369
skills have few examples; the exact counts there-
1370
fore take precedence over an assumed per-dataset
1371
ratio.
1372
Task identifiers are disjoint across partitions, but
1373
the skill vocabulary is deliberately shared: each
1374
partition contains all 306 retained gold skills. The
1375
evaluation consequently measures generalization to
1376
held-out tasks involving represented skills, rather
1377
than to entirely unseen skills.

C.2
Required-Skill Labels and Task Types
1379
Each instance has a task identifier and a nonempty
1380
annotated set of required skill identifiers. We use
1381
these released associations as the routing targets,
1382
preserving all labels of a retained task. TheoremQA
1383
concerns theorem application, LogicBench logical
1384
reasoning, ToolQA tool-use workflows, MedCalc-
1385
Bench medical calculators, CHAMP mathematical
1386
concepts, and BigCodeBench software-library use.
1387
All retained TheoremQA, LogicBench, ToolQA,
1388
and MedCalc-Bench tasks have exactly one anno-
1389
tated required skill. BigCodeBench and CHAMP
1390
also test recovery of multiple required skills.
1391
All 1,059 retained BigCodeBench tasks have
1392
multiple labels. CHAMP contains 90 single-skill
1393
and 78 multi-skill tasks. Across the six collec-
1394
tions, the retained data contain 6,932 task–skill an-
1395
notation occurrences, distinct from the 306 unique
1396
skills. The test split contains 1,097 annotation oc-
1397
currences over 748 tasks: 608 tasks have one re-
1398
quired skill and 140 have multiple required skills.
1399
The latter comprise all 123 BigCodeBench test
1400
tasks and 17 of the 26 CHAMP test tasks. Big-
1401
CodeBench test tasks require between two and
1402
six annotated skills; CHAMP test tasks require
1403
between one and four.
1404
Routing recall uses the entire annotated required
1405
set as its denominator, so recovering one relevant
1406
skill does not necessarily recover all requirements
1407
of a multi-skill task. For annotation-based preci-
1408
sion and F1, selected skills outside this set count as
1409
false positives. This convention defines the evalu-
1410
ation target; it does not imply that an unannotated
1411
skill cannot help a downstream agent. We do not
1412
replace a multi-skill target with a single representa-
1413
tive label.

1415
The shared SRA-Bench retrieval corpus contains
1416
26,262 distinct skill identifiers: 636 gold skills as-
1417

1418
25,626 web-collected distractors (Su et al., 2026).
1419
A skill record provides a name, description, and
1420
content, which may include instructions, formulas,
1421

1422
in the task collections resolve to records in this cor-
1423
pus. Filtering the task splits reduces the evaluated
1424
gold vocabulary to 306 skills; it does not reduce
1425
the shared retrieval corpus to those skills.
1426

1427
WeihangSu/SRA-Bench on Hugging Face, with the
1428
accompanying SR-Agents toolkit. The distributed
1429

1430

1431

1432
used for retrieval, routing, and oracle-conditioned
1433
