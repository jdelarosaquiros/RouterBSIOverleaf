As interaction histories grow, retaining all prior examples for checking each update also makes continual adaptation increasingly expensive. This creates a need for a routing mechanism whose applicability criteria are explicit and editable, but whose updates are efficiencly constrained by prior experience and independently checked for generalization. These problems of controlling regressions while bounding used experience serve as the motivation for our approach. We introduce RouterBSI, a recursive selfimproving algorithm for skill routing in a black-box setting called RouterBSI. It refines task applicability predicates using Minimum Bayes Risk (MBR) with bounded replay to minimize errors on seen tasks and a held-out validation gate to reduce regressions on unseen tasks. The router evaluates predicates for top-k retrieved skills then selects skills if the task satisfies their respective predicate. RouterBSI improves its cold-start top-5 recall of required skills by an average of 24.9% across different retrievers on tasks from TheoremQA, LogicBench, ToolQA, MedCalc-Bench, CHAMP, and BigCodeBench sharing a 26k skill corpus. On average, it retains 90.5% of the required skills in top 5 from the top 50 skills retrieved. Its top-5 recall is 75.5%, with relative recall improvements over baselines averaging 7.9% to 33.6% across retrievers. Our contributions are: • We propose RouterBSI, a non-parametric skillrouting framework that evaluates explicit applicability predicates over retrieved candidates, making routing criteria interpretable and directly editable without updating the underlying language model. • We develop a recursive self-improvement procedure that refines predicates from routing failures, selects updates through minimum Bayes risk over a bounded replay of relevant and irrelevant tasks, and rejects updates with higher held-out validation error than the cold-start predicate. • We evaluate RouterBSI on six SRA-Bench datasets with a shared 26K-skill corpus, achieving the highest aggregate nDCG@10 and Hit@1 among evaluated methods while ablations establish the contributions of replay and validation. 2 Related Works 2.1 Non-Parametric Routing Optimization Non-parametric routing optimization updates external routing state from task feedback while keeping model weights fixed. Experience-based methods revise memories and procedures, but revisions can undo earlier improvements (Wang et al., 2025b; Ouyang et al., 2026; Guo et al., 2024). Structural methods evolve skill relationships, but graph expansions can introduce many irrelevant skills, reducing precision or exceeding context limits (Zhang et al., 2025; Bai et al., 2026). Gated updates limit regressions through surrogate objectives or rollback criteria but don’t directly minimizing routing error on seen tasks (Mi et al., 2026; Shi et al., 2026). Similar to our approach, JTPRO evaluates candidates on sampled training minibatches and held-out validation but does not provide bounded experience management for online adaptation (Ghoshal et al., 2026). Retaining earlier routing corrections while bounding experience and evaluation costs remains a challenge. RouterBSI ensures non-decreasing empirical error on the retained set while bounding replay evaluation costs. A held-out gate additionally rejects updates that regress validation performance below the cold-start performance. 2.2 Parametric Routing Optimization Parametric routing optimization updates model weights using supervision, preferences, or execution feedback. Learned retrievers and rerankers score relevance or utility of skill for task (Qin et al., 2024; Zheng et al., 2026; Wang et al., 2026c; Li et al., 2026b; Zhou et al., 2026), while direct selectors predict which capability to invoke or whether invocation is needed (Wang et al., 2025a; Qian et al., 2025; Chen et al., 2026a). Reinforcementlearning policies optimize skill routing from downstream rewards (Wang et al., 2026b; Xia et al., 2026a; Zhang et al., 2026; Huang et al., 2026; Wu et al., 2026). These approaches require large training data and encode routing criteria implicitly in model weights.
