\subsection{Shared Configuration}
\label{app:implementation-settings}
The default configuration uses SkillSight with Qwen3.5-4B. Table~\ref{tab:appendix-settings} specifies the shared optimization settings. The retrieval budget is distinct from the downstream skill budget: the main router evaluates 50 candidates, whereas the fixed-size downstream variant supplies five skills after routing. We initialize the entire shared skill catalog and keep its membership and retrieval representations fixed while updating predicates.

The length limit counts characters, including spaces and punctuation, rather than tokens. Both MBR replay and the held-out gate are enabled. The replay loss is mean Boolean error; the validation score is the single-predicate specialization described in Appendix~\ref{app:procedure-validation}. There is no further truncation of the current-inclusive replay set. With $N=5$, it contains at most 11 distinct tasks.
