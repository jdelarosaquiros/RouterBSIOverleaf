\subsection{Predicate-Evaluator Validation}
\label{app:evaluator-validation}
We examine whether saved Boolean decisions follow the predicate-checking rules, separately from whether a skill is required. This diagnostic uses the final, tenth-iteration SkillSight/Qwen3.5-4B test run: 748 tasks with 50 candidate-predicate occurrences each. The source is explicitly \emph{noncanonical and nonreportable}: source drift was allowed, the final historical audit was disabled, and a runtime judgment cache could bypass exact request reconstruction. The checks below establish consistency of consumed artifacts and saved judgments, not canonical experimental validity.

A separate model, \texttt{gpt-6.1-sol}, adjudicated the same public task, predicate, and original checker rules using high reasoning effort in standard mode. It also saw the saved Boolean, but was instructed to determine the expected Boolean independently and return a strict structured verdict with a concise evidence rationale. Thus, this first review was not blinded. It evaluated predicate satisfaction rather than skill relevance or downstream answer correctness; required-skill annotations and skill contents were not supplied. Exact task--predicate--Boolean duplicates shared one review, yielding 37,350 unique reviews for 37,400 occurrences. All occurrences were reviewed, and repeated occurrences retain their original weight. Source checksums, journal-record hashes, request payloads, and occurrence-weighted counts were verified before tabulation.

\input{sections/appendix/evaluator_validation_table}

Table~\ref{tab:app-evaluator-validation} reports 36,315 agreements and 1,085 disagreements, or 97.10\% model-adjudicated agreement, not accuracy against human ground truth. Class imbalance substantially affects this aggregate: agreement is 35,606/36,217 for saved False decisions (98.31\%) but 709/1,183 for saved True decisions (59.93\%). Treating the adjudicator's expected Boolean only as a provisional reference, positive recall is 709/1,320 (53.71\%), while an always-False predictor would agree on 36,080/37,400 occurrences (96.47\%). The high pooled rate therefore does not establish reliable recognition of predicate-positive cases or validate the required-skill labels.

We additionally inspected 40 distinct reviews, excluding all 20 cases from an earlier audit. With seed 20261014, we sampled 20 reviews from each adjudicator-defined stratum: evaluator incorrect and evaluator correct. A second AI pass assessed the task--predicate pairs blinded to saved labels, first-review verdicts and rationales, and stratum; disagreements were then reconciled against the checker rules. In the incorrect stratum, 17 assessments were supported, one was likely incorrect, and two were ambiguous; all 20 correct-stratum assessments were supported. These judgments are AI-assisted qualitative checks, not human validation. All sampled correct-stratum decisions were originally False, so they provide no direct check of approved True decisions. The balanced sample is not prevalence-representative, is not pooled with the earlier audit, and cannot estimate full-cohort adjudicator accuracy.
