\subsection{Paired Routing Uncertainty}
\label{app:paired-routing}
We retrospectively compare saved SkillSight-routing outputs on the same 748 test tasks with matched required-skill annotations. The primary comparison uses RouterBSI run~1, matching the SkillSight-specific results in Tables~\ref{tab:app-routing-1}--\ref{tab:app-routing-3}; it does not provide uncertainty for the main table's cross-retriever average. Table~\ref{tab:paired-routing-uncertainty} reports task-weighted differences against five baselines. We use nDCG@1 as the primary endpoint, with nDCG@10 and MRR@10 as secondary endpoints. MRR@10 averages the reciprocal rank of the first required skill within the first ten positions, assigning zero when none occurs. All saved outcomes, including fallback selections and empty selected sets, are retained with their native rankings.

\paragraph{Paired resampling.}
We compute 50,000 paired bootstrap replicates, stratified by dataset, using PCG64 with seed 20261013. Exact-question groups form 747 clusters, including one two-task ToolQA cluster. Each replicate samples the original number of clusters with replacement within each dataset, retaining all member tasks. We divide each dataset's summed taskwise differences by its sampled task count and combine dataset means using the fixed original task proportions $n_d/748$. The same draws serve every comparison and endpoint. Brackets are the 2.5th and 97.5th percentiles with linear interpolation. They are pointwise intervals, without multiplicity correction or statistical-significance claims. This procedure assumes independent, exchangeable question clusters within each dataset; dependence beyond exact duplicates may remain.

\paragraph{Fixed-system sensitivity.}
The second panel first averages each task's metric over three saved RouterBSI systems, then subtracts the baseline score. It does not pool repeated tasks, ensemble rankings, or resample training runs. The runs share a seed but differ in initialization and source configuration, so this is not an independent-seed robustness estimate. The smallest primary nDCG@1 gap is against SkillRouter: $9.49$ percentage points, with interval $[6.02,12.97]$; the corresponding three-system sensitivity is $7.66$ points, with interval $[4.45,10.89]$.

\paragraph{Scope and eligibility.}
These intervals describe conditional task-sampling uncertainty for fixed saved systems and a fixed dataset mixture, not downstream success or training variability. Candidate pools and ranking policies are not identical across all methods, so these are whole-system comparisons rather than controlled shared-candidate ablations. The RouterBSI archives remain noncanonical and nonreportable, with source-drift and disabled-final-audit caveats. This analysis-only addition does not change that eligibility status.
